AI 错题复盘工作台（Windows 本地版）

使用方法
1. 将整个文件夹解压到可写目录，不要只复制 exe。
2. 双击 start.bat，浏览器会自动打开。
3. 使用结束后双击 stop.bat。
4. 学习记录保存在本文件夹的 data 目录。

注意
- 无需安装 Python 或 Node.js。
- 默认仅监听 127.0.0.1，不对局域网或互联网开放。
- 请不要把工作台放在 Program Files 等普通用户不可写目录。
- 完整备份不包含 API Key，恢复后需要重新填写模型密钥。
- 移动整个程序文件夹前建议先停止工作台并下载完整备份。
- 本地API仅供工作台使用，Release默认不开放Swagger UI和OpenAPI文档。
- 本程序尚未代码签名，请从正式发布页下载并核对SHA-256。

隐私、安全、项目许可、第三方许可和SBOM参见程序根目录中的对应文件。
