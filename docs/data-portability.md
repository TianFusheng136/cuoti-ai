# 数据备份与恢复

## 完整备份

设置页的“下载完整备份”会生成 ZIP 文件，包含：

- SQLite 数据库的一致性快照；
- 用户上传的原始题目图片；
- 备份格式、版本和数据库版本清单。

完整备份始终排除：

- DPAPI 加密的 API Key 文件；
- 日志；
- 运行状态文件；
- 临时导出文件。

## 恢复

恢复分为两步：

1. 当前进程验证并暂存备份；
2. 用户通过 `stop.bat` 停止，再使用 `start.bat` 启动，应用在打开数据库前执行替换。

恢复过程检查 ZIP 路径穿越、符号链接、重复项目、文件数量、解压总大小、清单版本、数据库版本和 SQLite 完整性。如果替换失败，应用尝试回滚到原数据库和图片目录。

恢复后的模型配置会保留服务类型、Base URL 和模型名称，但全部禁用且不再引用本机已有密钥。用户必须在设置页重新填写 API Key 后才能启用。

## 错题本导出

设置页支持 JSON 和 CSV 两种只读导出：

- JSON 保留列表结构，适合程序处理；
- CSV 使用 UTF-8 BOM，便于 Windows 表格软件打开。

导出包含题目、学科、年级、知识点、真实错因、掌握状态和复习时间，不包含 API Key。

## 格式版本

当前完整备份格式：`ai-error-review-backup` / `1`。

恢复端只接受已知格式和数据库版本。未来修改备份格式时必须提升 `format_version` 并提供显式迁移策略，不能猜测性导入未知数据。
