# ADR-0001：发布版采用本地单进程架构

- 状态：已接受
- 日期：2026-07-21

## 决策

开发模式使用 Vite 与 FastAPI 分别启动；Windows 发布版由 FastAPI 同时提供构建后的 React 静态资源和 `/api/v1` 接口，仅监听 `127.0.0.1`。

发布包将使用 PyInstaller 封装 Python 后端，普通用户无需安装 Python、Node.js 或 Docker。

## 原因

- 降低普通用户的启动和排障门槛；
- 避免跨域和多进程管理；
- 保留前后端独立开发体验；
- 不引入本地反向代理或外部服务器。

## 后果

- 前端必须先构建再进入发布包；
- SPA 路由回退由 FastAPI 处理；
- 后端不得监听局域网地址；
- Release 构建必须在全新 Windows 环境验证。
