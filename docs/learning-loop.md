# 学习闭环说明

## 真实错因

分析模型只能给出候选错因，页面不会把候选项冒充成学生真实想法。学生可以从概念、计算、审题、方法、粗心和其他原因中自主选择，并补充自己的说明。

真实错因与 AI 分析分开保存。重新分析题目不会覆盖学生已经填写的错因。

## 三类变式题

只有存在完整、通过 Schema 校验的分析时才能生成变式题。生成器只接收分析中的学科、年级、整理后的题目、知识点、难度和整体思路，不读取原始未确认内容。

每次必须依次生成：

1. `same_point`：同知识点巩固；
2. `new_context`：换场景迁移；
3. `challenge`：提高难度。

变式题采用混合安全流水线：

- 已有确定公式并完成不变量测试的题族，使用本地安全题型生成器计算题干、答案和解析；当前覆盖抛物线斜弦三角形面积最值、绝对值方程、坐标中点与三角形面积、功和功率/效率。每类数值从经过约束的参数组中选择，并再次检查交点、解集、面积、最值、单位或效率边界；执行引擎会明确显示为 `deterministic-*-v1`。
- 其他题型仍由已配置文本模型按 `same_point`、`new_context`、`challenge` 分别设计。盲解阶段看不到候选答案，学生版答案单独整理，最终再独立求解核对；只有失败类型会携带具体原因定向重试，已经通过的类型不会重复生成。

两条路径都必须通过严格 Pydantic Schema、自我纠错文字检查和题干有效性检查。失败结果不会作为可用变式题保存，页面会给出原因并允许重新生成。确定性校验只覆盖上述明确题族；其他题型的二次验算仍是 AI 校验，不是形式化证明，答案和解析继续默认折叠并提示人工核对。

## 错题本

完成分析的题目会自动进入本地错题本。支持：

- 题目或知识点搜索；
- 学科筛选；
- 知识点筛选；
- 待复习、复习中、已掌握筛选；
- 收藏筛选；
- 返回原结构化复盘。

## 复习计划

新完成的错题默认进入今日待复习。学生复习后自行选择：

- **还没想起来**：成功次数归零，安排 1 天后复习；
- **我记得方法**：按 1、3、7、14、30、60 天逐步延长间隔；
- 连续三次记得后标记为“已掌握”。

每次复习结果单独写入 `review_events`，用于保留本地复习轨迹。

## 数据库升级

项目使用 Alembic 管理数据库版本：

- `0001`：题目、附件、模型、识别、确认和分析；
- `0002`：真实错因、变式题和复习计划。

旧版数据库首次启动时会标记为 `0001` 后升级到最新版本，已有题目和分析不会删除。已经完成分析的旧题会自动加入复习计划。
