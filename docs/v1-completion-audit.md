## 第一版核心问题

这个项目第一版解决的核心问题是：**把学生的一道错题经过“录入/识别—人工确认—结构化复盘—错因记录—变式练习—本地复习”转化为可持续复习的本地学习记录。**

### 第一版必须完成

1. 文字/单张题目图片录入；
2. 图片 OCR/视觉识别；
3. 人工修改并明确确认题目；
4. 学科、年级、学生答案与过程补充；
5. 结构化分析：知识点、答案、思路、步骤、错因、记忆句和三项检查；
6. 三类正确且有区别的变式题，并可查看答案、重新生成；
7. 错题保存、修改、删除、筛选和间隔复习；
8. 重启持久化；
9. 模型错误、异常输入和重复点击有明确反馈；
10. Windows 独立包可在无 Python/Node 的环境运行。

### 可后续完成

- 更多原生模型适配器和真实服务商兼容矩阵；
- 形式化数学证明器、符号代数和物理量纲校验；
- 自动修复未通过验算的变式题；
- 精确 Token/费用统计；
- 代码签名、CI 和正式 GitHub Release；
- 多图、PDF、HEIC、手写专项模型；
- 账号、云同步、班级、支付和移动原生应用。

### 当前明确不支持

- 离线本地大模型；
- PDF、GIF、HEIC、音频、视频和一道题多图；
- 公网部署、局域网共享、多用户隔离；
- 保证 OCR、答案或变式题 100% 正确；
- 自动判定学生真实错因；
- 对所有 OpenAI 兼容服务都保证兼容。

### 对外不能宣传

- “完全离线”或“题目绝不离开电脑”；
- “答案绝对正确”“AI 自动验算保证无误”；
- “三类变式题每次都能成功生成”；
- “支持所有模型/所有学科/所有图片格式”；
- “正式发布版已完成”或“已通过代码签名”。

### 成功变式题抽查

绝对值方程的三类结果：

- `same_point`：`|3x+2|=7`，直接巩固绝对值方程；
- `new_context`：温度/数轴距离场景，核心仍是绝对值方程；
- `challenge`：加入参数 `a`，难度从 basic 到 medium，未超出八年级常规代数范围。

答案经人工复算与二次验算一致。重新生成前后 run ID 分别为 `1202c3ef-...` 和 `f557abf5-...`，三个位置题目均不同。

### 变式题审计结论

- 结构 Schema 能保证字段和三种类型，不能单独保证数学正确；
- 本次新增独立二次审题，成功拦截了用户此前发现的同类错误；
- 页面会展示具体失败原因并允许重试，不白屏、不保存错误草稿；
- 但复杂坐标几何和物理题连续三次不能产出合格结果，属于 **P1 可用性问题**；
- 因此三类变式练习目前不能作为“稳定可交付能力”宣传。

## 数据与隐私

### 本地保存内容

- `data/app.db`：题目元数据、确认文本、学生答案/过程、识别/分析/变式记录、错因、收藏、复习事件、模型配置元数据；
- `data/uploads/`：原图；
- `data/config/secrets/`：DPAPI 密文；
- `data/exports/`：备份和导出；
- `data/logs/`：服务访问/错误日志；
- `data/runtime/`：进程状态和待恢复文件。

SQLite `PRAGMA integrity_check` 返回 `ok`，WAL 模式。3 道审计题在停止并重新启动后均恢复。

修改/删除实测：确认文本、学科、学生答案和过程可更新；删除返回 204，随后读取 404，7 张相关表残留行均为 0。错题本现已增加删除入口。

### 发送给模型的内容

- 视觉识别：原始图片和识别提示词；
- 分析：人工确认文本、学科、年级、学生答案和学生过程；
- 变式生成：整理后的题目、学科、年级、知识点、难度、整体思路；
- 变式验算：上述依据和候选题/答案/解析；
- 连接测试：API Key 作为请求头，不发送题目。

题目仅在用户触发识别、分析或变式时发送给所选 AI 服务商。项目作者没有中转服务器。

### API Key 与日志

- Key 只在设置提交时经 `127.0.0.1` HTTP 发送到后端；
- 后端用当前 Windows 用户 DPAPI 加密；
- 列表响应只返回 `••••••••`，不返回明文或密钥文件引用；
- 备份/JSON/CSV 不含 Key；
- Uvicorn 日志只看到方法、路径、状态和题目 UUID，没有请求体、图片、答案或 Key；
- 前端源码和浏览器存储未保存 Key。

真实边界：这不是“所有处理完全本地”。学习数据本地保存，但调用第三方模型时相应内容会离开本机。任何能以同一 Windows 用户运行的恶意程序、能读取项目目录的本地账号、或能访问本机 `127.0.0.1:3002` 的本地进程，都可能读取未加密的 SQLite/图片或调用本地 API；DPAPI 主要防止密钥文件被复制到其他用户/机器后直接解密，不防同用户恶意程序。

## 模型与配置

代码层支持：

1. OpenAI 兼容 Chat Completions；
2. Gemini 原生 REST `generateContent`。

真实验证：MiMo `mimo-v2.5-pro` 文本和 `mimo-v2.5` 视觉；两项 `/models` 连接测试分别 276ms、261ms。Gemini 仅通过 MockTransport 自动化测试，没有真实 Key 验收。

前端把选中的 `provider_id` 发给后端，后端记录实际 provider/model，因此切换不是假按钮。OpenAI 兼容接口在 `json_schema` 被拒绝或返回不兼容 JSON 时会尝试 `json_object`/显式 Schema；最终仍不合法则拒绝保存。

超时可配置 5–300 秒。没有通用网络自动重试；用户可点击重试。分析格式修复可能产生第二次调用；变式题至少两次调用（生成+验算），格式回退会更多。本应用没有保存 usage，因此不能给出精确 Token/费用。真实耗时见端到端证据。
