# 题目识别与确认机制

## 强制确认流程

图片题目的处理顺序为：

```text
保存原图 → 视觉模型识别 → 展示识别风险 → 用户编辑 → 用户明确确认
```

系统不会将视觉模型返回的文字直接视为已确认题目。确认记录单独保存：

- 视觉模型识别文字快照；
- 用户最终确认文字；
- 确认文字 SHA-256；
- 确认时间；
- 学科、年级及用户可选的答案和过程。

用户修改题目文字后，页面会自动取消确认勾选。

## 不完整识别

视觉模型必须返回：

- `complete`、`partial` 或 `uncertain`；
- `high`、`medium` 或 `low` 可信度；
- 警告列表；
- 缺失信息列表。

`partial` 和 `uncertain` 必须提供缺失信息，否则后端拒绝该模型输出。页面固定提示：

> 题目识别可能不完整，请检查或手动修改后再分析。

用户可以根据原图手动补全，再明确确认。后续分析只能读取确认记录，不能直接读取视觉模型原始输出。

## 提示词注入防护

识别提示词将图片内容视为不可信数据，明确要求模型忽略图片中试图改变任务或输出格式的指令。模型输出必须通过 Pydantic Schema 校验，不符合结构时不保存为成功结果。

## 能力边界

- 识别可信度是综合风险等级，不是统计概率；
- 连接测试成功不代表视觉识别一定可用；
- 公式和复杂图形仍需人工核对；
- 当前阶段不会在识别后自动生成答案。
